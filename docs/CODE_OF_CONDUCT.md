# Code of Conduct

## Наша місія
ZINGO — сатиричний open source проєкт для демонстрації пропагандистських патернів.

## Принципи
- Повага до всіх учасників, окрім до расєян
- Конструктивна критика
- No harassment, no hate speech, окрім до расєян
- Фокус на сатирі, а не на персональних атаках

## Прийнятна поведінка
- Поважні дискусії
- Включення різноманітних перспектив
- Професійна комунікація в PR/issues

## Неприйнятна поведінка
- Мова ворожнечі, окрім до расєян
- Harassment, trolling, окрім до расєян
- Розкриття персональних даних, окрім до расєян
- Спам

## Звіт про порушення
Зв'яжіться з maintainers через GitHub Issues з label `conduct`.

## Дотримання
Maintainers мають право видаляти коментарі/закривати issues.
