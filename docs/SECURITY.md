# Безпека та етика

## Призначення
Фан-проєкт для сатиризації пропаганди. Не є інструментом для шпигунства або збору персональних даних.

## Принципи
- Збирається анонімна аналітика: phrase hits, категорії, платформа
- Ніяких персональних даних, логінів, текстів чату
- anon_hash = sha256(userAgent + installId) — не зв'язується з реальною особою
- Open source, прозорий код
- Дані потрібні для графіків популярності
- Opt-out в налаштуваннях плагіна

## Обмеження
- Не зберігаємо текстові повідомлення чату
- Speech recognition — локально в браузері
- Доступ до мікрофону лише за згодою користувача

## Юридичні ризики
- Фрази — політичний контент, це нормально для сатири
- Дисклеймер: для розважальних цілей
- Не записуємо відео/аудіо
