# UI дизайн

## Принципи
- Невидимий, коли не потрібен
- Мінімалістичний, темна тема за замовчуванням
- Не заважає чату
- Швидкі відмітки

## Компоненти

### Bingo Card Overlay
Позиція: right / left / bottom
Розмір: 5x5 клітинки
Кожна клітинка:
- Текст фрази
- Категорія кольором
- Вага як маленька зірочка
- Клік → toggle marked

### Toast підтвердження
"Схоже, що почув 'братські народи'"
[Так] [Ні] [Ігнорувати]
Авто-зникнення за 5 сек

### Popup
- Нова гра / продовжити
- Вибір картки
- Статистика сесії
- Експорт

### Options
- Сайти для інжекту
- Speech ввімкнено/вимкнено
- Мова UI
- Звуки
