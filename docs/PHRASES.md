# База фраз ZINGO — Російська пропаганда

> **Важливо:** Ця база містить **тільки російські пропагандистські наративи, дезінформаційні тропи та маніпулятивні техніки**. Українські патріотичні фрази (Слава ЗСУ, Героям слава, Перемога тощо) **НЕ** входять до цієї бази — вони не є пропагандою.

---

## Категорії та ваги

Вага (1-10) визначає ймовірність вибору фрази при генерації картки. Вища вага = частіше зустрічається в пропаганді.

## Категорії для генерації карток

```typescript
type PhraseCategory = 
  | 'war_narrative'        // Наративи про війну/СВО
  | 'delegitimization'     // Делегітимізація України
  | 'denazification'       // Нацизм/денацифікація
  | 'biolabs'              // Біолабораторії
  | 'west_nato'            // Захід/НАТО/США
  | 'history_revisionism'  // Історичний ревізіонізм
  | 'manipulation'         // Маніпуляції/газлайтинг
  | 'disinfo_ua'           // Дезінформація про ЗСУ/Зеленського
  | 'economy'              // Економічні наративи
  | 'values_religion';     // Ціннісні/релігійні
```

## Нормалізація фраз

При додаванні/пошуку фраз застосовується нормалізація:
1. **Низький регістр** — `toLowerCase()`
2. **Видалення пунктуації** — `.replace(/[.,!?;:()]/g, '')`
3. **Нормалізація пробілів** — `.replace(/\s+/g, ' ').trim()`
4. **Об'єднання варіантів** — синоніми групуються під одним `id`

**Приклад:**
```
"Специальная военная операция!" 
→ "специальная военная операция"
→ id: "svo", category: "war_narrative", weight: 10
```

- Офіційні заяви МІД РФ / МО РФ
- Фактчеки: StopFake, VoxCheck, BBC Verify, Reuters Fact Check
- Звіти EUvsDisinfo, DFRLab, Bellingcat

## Оновлення бази

1. Фрази додаються через PR з джерелом (посилання на промову/статтю/пост)
2. Вага узгоджується з командою (1-10)
3. Категорія призначається автоматично за ключовими словами
4. Дублікати об'єднуються (варіанти додаються до існуючого `id`)
